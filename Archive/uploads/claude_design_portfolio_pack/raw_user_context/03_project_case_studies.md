## Кейс 1 — Tessora Task Portal (многотенантный SaaS)
**Роль:** Ведущий разработчик (74% коммитов) · **Стек:** Next.js, TypeScript, Prisma, PostgreSQL, Web Push, Telegram

Многотенантный портал управления задачами с ролевой моделью и жизненным циклом контента.

**Что сделал:**
- Спроектировал схему данных (Prisma/PostgreSQL) с изоляцией по `companyId` и **RBAC на 7 ролей** (super_admin, PM, creator, client_owner/manager/viewer).
- Реализовал **стейт-машину статусов задач**: `NEED_TO_DO → IN_PROGRESS → ON_REVIEW → ON_REVISION → APPROVED`.
- Внедрил уведомления: **Web Push (VAPID)** + интеграция с **Telegram**.
- Объединил маршруты задач, сделал адаптивный UI и пагинацию.

**Ключевое:** архитектура доступа и данных, а не только интерфейс.

## Кейс 2 — M-Manager / Monster-Manager (Telegram-бот управления)
**Роль:** Единственный разработчик (87–93% коммитов) · **Стек:** Python, aiogram, SQLAlchemy (async), PostgreSQL

Telegram-бот для управления командой и удалёнными сотрудниками с ролевой логикой.

**Что сделал:**
- Async-архитектура на **aiogram** с разделением на роутеры, клавиатуры, конфиг и сервис-слой.
- **UserService** с паттерном `get_or_create`, работа через `AsyncSession`.
- Ролевое поведение (напр. определение удалённых сотрудников), напоминания по расписанию с фильтрацией по ролям и дате.
- Русскоязычный UX, инлайн-меню.

**Ключевое:** полностью самостоятельный бэкенд-продукт от архитектуры до прода.
`[ссылка]` · `[демо-бот]`

## Кейс 3 — CGAI / Monster-Express (AI-платформа контента)
**Роль:** Ключевой контрибьютор (≈48% в команде из 7) · **Стек:** React, TypeScript, Tailwind, HLS video, Cloudflare Stream, i18n

Маркетинговая AI-платформа с тарифами, видеоконтентом и WhatsApp-воронками заказов.

**Что сделал:**
- Компоненты тарифов с **Swiper**, ленивой загрузкой видео и fallback-конфигами.
- Потоковое видео через **HLS / Cloudflare Stream**, кастомный видеоплеер.
- Мультиязычность (**react-i18next**), Redux-состояние.
- **WhatsApp-сценарии заказов** и UX-оптимизация воронки.

**Ключевое:** сложный интерактивный фронтенд + продуктовые интеграции в командной разработке.

## Кейс 4 — Klimat-Profi / English-Point (клиентские сайты «под ключ»)
**Роль:** Единственный разработчик (100% коммитов) · **Стек:** Next.js, Django, Directus (CMS), Tailwind

Клиентские сайты, сделанные полностью в одиночку — от бэкенда до вёрстки и деплоя.

**Что сделал:**
- Бэкенд на **Django**: модели, миграции, admin-панель (fieldsets, readonly, кастомные ModelForm), формы заявок.
- Фронтенд на **Next.js + Tailwind**, контент через **Directus (headless CMS)**.
- Интеграция Telegram-уведомлений о заявках, адаптивная вёрстка.

**Ключевое:** доказанная способность вести проект в одиночку end-to-end.
