# ТЗ для Claude Design — Portfolio Website для Даниэла Кубанычбекова

## 1. Контекст

Нужно создать дизайн-концепт личного portfolio website для разработчика.

Имя:
Даниэл Кубанычбеков

Основное позиционирование:
Frontend-focused Full-Stack Developer

Главный акцент:
Frontend-разработка, React, TypeScript, Next.js, UI, производительность, адаптивность, современный интерфейс, аккуратные анимации.

Backend показывать как дополнительную силу:
Python, FastAPI, Django, aiogram, PostgreSQL, API, интеграции, production deployment.

Цель сайта:
Сайт нужен для поиска работы и отправки работодателям/командам как профессиональный профиль. Он должен показывать уровень, вкус, техническое мышление и способность доводить продукты до production.

Важно:
Все проекты нужно показать обезличенно. Нельзя использовать реальные названия клиентов, ссылки на production, ссылки на репозитории, приватные данные, реальные бизнес-данные или скриншоты без блюра.

## 2. Главная идея сайта

Сайт должен создавать ощущение:

"Это frontend-разработчик, который умеет делать не просто интерфейсы, а сильные production-ready продукты с хорошей архитектурой, скоростью, UX и пониманием backend/integrations."

Главная фраза для hero:

Frontend Developer
with Full-Stack Experience

Подзаголовок:

Создаю быстрые, современные и production-ready интерфейсы на React / TypeScript / Next.js. Понимаю backend, базы данных, API-интеграции и полный цикл вывода продукта в production.

Альтернативный вариант:

React · TypeScript · Next.js · Python

Создаю интерфейсы, которые выглядят современно, работают быстро и готовы к реальному production.

## 4. Стиль дизайна

Нужен тёмный современный сайт.

Modern developer portfolio
Cinematic but clean
Fast, sharp, confident

Визуальное ощущение:

- premium/grid/bento композиция;

## 21. Анимации

Нужны хорошие анимации, но сайт должен оставаться быстрым.

Использовать:
- scroll reveal;
- hover animations;
- animated counters;
- floating tech cards;
- subtle gradient movement;
- cursor glow;
- smooth section transitions;
- project card hover preview;
- micro-interactions на кнопках и тегах.

Не использовать:
- тяжёлые 3D-сцены на весь экран;
- анимации, которые мешают читать;
- постоянное движение всего сайта;
- долгие loader-анимации;
- excessive parallax.

Правило:
Анимации должны усиливать премиальность, а не ухудшать UX.
