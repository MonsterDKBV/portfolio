# Claude Design Portfolio Pack

This folder is prepared for Claude Design.

## Goal
Redesign and improve a personal portfolio website for a frontend developer.
The previous attempt was not strong enough visually and the content also needs refinement.

## What is inside
- `context/` — distilled context and requirements
- `references/portraits/` — portrait photos
- `references/project_screens_blurred/` — safe blurred project previews
- `references/style/` — base design system direction
- `raw_user_context/` — raw materials from previous work

## Main instruction
Do not simply reuse the old blocks or imitate them mechanically.
Use the context and references to create a stronger, more art-directed concept.

## What the user wants
- A visually strong portfolio
- Frontend-focused positioning
- Premium dark style
- Better resemblance to Resend quality
- More creativity: additional lines, pseudo-3D, modern glass touches
- Better content and more human tone
