# Base Style Reference — Resend / Refero

Primary base URL:
https://styles.refero.design/style/0d914ef0-fa84-4c60-a9aa-cef0b5eb6e5d

## Core idea
Use Resend as the **base inspiration**, but do not clone it literally.
The final design must feel:
- premium
- dark
- restrained
- technical
- modern
- more creative than a direct Resend imitation

The current site attempt felt too generic and too far from Resend.
This redesign must improve both:
1. design quality
2. content quality

## Mood
- black velvet
- graphite hairlines
- white / bone-white text
- sharp developer feeling
- premium interface
- subtle violet accents
- mono details
- editorial display type in the hero
- pseudo-3D and structured line work

## Essential tokens
- Background: #000000
- Hairline border: #292d30
- White: #ffffff
- Bone white: #f0f0f0
- Muted text: #a1a4a5
- Secondary muted: #abafb4
- Accent violet: #9281f7
- Violet glow: #baa7ff

## Typography direction
- Hero display: Domaine / GT Sectra / Tiempos / similar editorial serif
- UI / body: Inter / Söhne / clean system sans
- Section display: aBC Favorit / strong geometric sans
- Mono details: Commit Mono / JetBrains Mono / IBM Plex Mono

## Structural rules
- Page canvas is pure black.
- Cards should be separated with 1px hairline borders, not heavy shadows.
- Buttons should stay restrained, mostly ghost / outlined.
- Violet must be used as a controlled accent, not everywhere.
- Do not flood the page with gradients or childish code decorations.

## Visual additions requested by the user
The user explicitly wants the redesign to go beyond plain Resend:
- add additional line work
- add subtle pseudo-3D elements
- use a more art-directed hero
- introduce selective glass / glassmorphism touches in some areas
- keep the overall system elegant, premium, and believable
- avoid looking AI-generated, generic, or template-like

## Important
The result should be inspired by Resend, but should feel like a **creative portfolio for a frontend developer**, not like a copied SaaS landing page.
