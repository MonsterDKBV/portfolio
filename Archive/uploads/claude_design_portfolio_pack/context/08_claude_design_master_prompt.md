# Master Prompt for Claude Design

You are acting as a senior product designer + web art director.

Your task is to redesign a personal portfolio website for a frontend developer.

You must NOT simply reuse the previous weak blocks or imitate them mechanically.
You must improve the overall design quality, the content quality, and the art direction.

## Main objective
Create a visually strong, premium, dark portfolio website that:
- is intended for job search
- positions the owner as a Frontend Developer
- feels inspired by Resend quality
- but evolves beyond a direct Resend clone
- includes more creativity: extra lines, pseudo-3D details, subtle glass touches
- feels modern, intentional, and not AI-generic

## Files to read first
Read everything inside:
- `context/`
- `references/style/`
- `references/portraits/`
- `references/project_screens_blurred/`
- `raw_user_context/` (optional additional context)

## Important role positioning
The owner is NOT targeting a Full-Stack role.
Do not sell him as Full-Stack in the hero or primary positioning.
Backend knowledge can be mentioned as supporting context only.

Use a primary title like:
- Frontend Developer
and a supporting sub-line around React / TypeScript / Next.js / production interfaces

## Content instructions
The current content still needs refinement.
Rewrite and improve the copy.

The new copy should be:
- simpler
- clearer
- more human
- less marketing-heavy
- believable
- strong enough for HR, hiring managers, and other developers

Avoid overcomplicated project naming.
Use simple project framing that the owner can explain comfortably.

## Design instructions
Base style reference:
https://styles.refero.design/style/0d914ef0-fa84-4c60-a9aa-cef0b5eb6e5d

Interpret the Resend system through:
- black canvas
- white / bone-white typography
- graphite hairline borders
- editorial hero typography
- mono metadata
- violet accent discipline

But improve the outcome with:
- stronger composition
- custom structural line work
- pseudo-3D forms
- subtle glass areas in selective places
- more expressive selected work presentation
- a more polished visual identity overall
