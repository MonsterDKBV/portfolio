# Do / Don't

## Do
- Keep the site frontend-focused
- Use Russian as the main language
- Improve the copy instead of blindly reusing old text
- Make the site feel custom and art-directed
- Use the provided project refs and portrait refs
- Build a more convincing selected work section
- Preserve clarity and professionalism

## Don't
- Don't copy Resend literally
- Don't overuse gradients or childish code graphics
- Don't push Full-Stack positioning
- Don't fill everything with purple
- Don't make it feel like a generic AI landing page
- Don't use heavy marketing wording
- Don't create project descriptions that the owner cannot explain himself
