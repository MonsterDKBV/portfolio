# Profile & Positioning

## Core identity
- Frontend developer
- Main stack: React / TypeScript / Next.js
- Can work with complex interfaces, dashboards, admin panels, content-heavy pages, catalog structures
- Understands production workflows and real project constraints
- Understands some backend concepts, APIs, databases, and integrations, but should not be sold as a backend/full-stack candidate

## Additional strengths
- Adapts quickly to unfamiliar tools and codebases
- Can study documentation fast and work safely inside existing systems
- Strong with AI-assisted engineering as a workflow advantage, but is NOT a vibe coder

## AI-assisted engineering message
This should be presented carefully:
He uses Claude Code, agents, skills, project context, and structured prompting
to accelerate analysis, decomposition, and implementation,
but final responsibility, logic, and decisions stay with him.

## Tone of self-presentation
- calm
- real
- not over-marketing
- not arrogant
- not junior-chaotic
- should feel like a thoughtful, promising frontend developer
