# Content Direction

The existing content still needs work.

## Problems to avoid
- too much generic marketing language
- too many empty buzzwords
- too much 'full-stack'
- descriptions that feel artificial or AI-generated
- jargon that even the owner would not naturally use

## Desired tone
- simpler
- clearer
- more honest
- more human
- more believable
- still polished

## Example preference
Instead of:
'Confidential POS System'

Prefer:
'Система заказов для чайханы'

Instead of overcomplicated descriptions,
use direct language explaining what the interface does and why it mattered.

## Important
The user himself should be able to confidently explain every case shown on the site.
If a project name or wording feels unnatural to him, it should be simplified.
