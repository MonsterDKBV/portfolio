# Design Direction

## Main problem with the previous attempt
The previous preview did not feel close enough to Resend quality.
It looked too generic, too AI-generated, and too mechanically assembled.

## What must improve
1. Hero art direction
2. Page rhythm and composition
3. Component sophistication
4. Better type hierarchy
5. Better use of empty space
6. Better visual storytelling in project blocks
7. More believable premium feel

## Creative direction
Base inspiration:
- Resend / Refero style system
But evolve it into a more individual portfolio language.

## The user explicitly wants
- additional lines
- pseudo-3D elements
- subtle glass feeling in some areas
- more modern / iPhone-like sophistication
- stronger wow-effect
- still dark and premium

## Suggested design ideas
- Use a large, art-directed hero composition rather than a plain split section
- Combine portrait + geometric object / pseudo-3D system
- Add controlled structural lines or grid traces in the background
- Use elegant layered panels for selected work
- Present projects in a stronger editorial way
- Use mono labels and metadata for developer flavor
- Use violet only as a signature accent

## Important constraint
Do not turn it into a noisy dribbble shot.
The design should still feel hireable, not just flashy.
